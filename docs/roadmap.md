# Delivery Roadmap

The PRD organises delivery into six outcome-based milestones. Each milestone
has explicit exit criteria and a definition of done. We re-validate the
milestone before moving to the next.

| # | Milestone | Status | Exit criteria |
|---|---|---|---|
| M0 | Service & Governance Baseline | ⬜ Pending | Service catalogue approved, DPIA drafted, retention classes agreed |
| M1 | Platform Foundation | 🟡 In progress | Staff can authenticate via Keycloak, access-control tests pass, clean deployment + restore succeed, health endpoint reports healthy |
| M2 | Operational Vertical Slice | ⬜ Next | One operational request type works end to end in UAT (call/web intake → acknowledgement → assignment → reply → resolution) |
| M3 | IT Separation & Cross-Domain | ⬜ | IT domain separated; sanitised child-ticket pattern works; cross-domain privacy tests pass |
| M4 | P0 Channels & Pilot Readiness | ⬜ | P0 acceptance criteria (PRD §33) met in selected office |
| M5 | P1 Omnichannel | ⬜ | WhatsApp, requester portal, knowledge, CSAT, e-Estate validation live |
| M6 | Optimisation | ⬜ | Advanced ITSM, CTI, monitoring, flow analytics, HA/DR automation |

## Current sprint

Goal 1 (this session) targets **M1 exit**. Goals 2–4 cover M2 and M3.
