# Agent Guide (P0)

This is a placeholder for the agent-facing user guide. Full content is
delivered alongside Milestone 4 (P0 Channels) and refined in UAT.

## What you will do day to day

- Receive enquiries from the call centre, walk-in, web form and email
- Create or update a ticket using the intake screen that fits the channel
- Triage, assign and work tickets from the queue or Kanban board
- Reply to requesters using approved templates
- Use the IT child-ticket flow when something is technically blocked
- Meet the SLA targets set for your service and priority

## Hard rules

- A requester never sees an internal note
- A requester never gets ticket content from the other domain
- A ticket is not a formal filing — say so when appropriate
- MFA is mandatory; password sharing is a disciplinary matter
- All actions are audited; the audit trail is the source of truth
